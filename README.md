# Managed CI sandbox

Disposable integration test for Ubicloud Linux and Namespace macOS runners.

The existing [npm publishing canary](npm-publishing-canary/README.md) also
qualifies the organization publisher. Its [fresh release E2E route](npm-publishing-canary/RELEASE.md)
adds checked Changesets generation and an owner PR chain while retaining the
original CI archive, registry readback and installed consumer.
